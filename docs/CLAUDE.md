# docs/

Working session notes. Excluded from the build tarball via `.Rbuildignore`; not package documentation.

## Files

| File | What | When to read |
| --- | --- | --- |
| `CONTINUE.md` | Session resume brief: access details, verified-working status, fixed defects, outstanding upstream-API work | Resuming an in-flight work session, checking what was already fixed before re-investigating |

Package API documentation is generated into `man/` from roxygen comments in `R/*.R`; architecture and rationale live in `README.md` at the repository root and in `R/README.md`.
