# .claude/plans/step-3-cost-model/

Planner state for the cost-model work. Written by the planner, moved here from a
temp directory; treat as a record of what was decided, not as a live document.

## Files

| File | What | When to read |
| --- | --- | --- |
| `plan.json` | The authoritative plan: 3 milestones, decisions `DL-011`..`DL-030`, 10 risks, per-card acceptance criteria | Checking what a milestone requires, or what a decision id says |
| `context.json` | The context the plan was built from: task spec, constraints, entry points, rejected alternatives | Understanding why an approach was ruled out before proposing it again |
| `qr-plan-design.json` | The quality-review items the plan was checked against | Reviewing whether a plan change breaks a review criterion |
